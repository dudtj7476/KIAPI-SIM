실행 환경 및 빠른 시작 가이드 (Quick Start)

프로그램 구동을 위한 권장 시스템 사양, 첫 가상 주행부터 정량 검증·보고서 출력까지의 기본 실행 절차, 그리고 화면별 키보드·마우스 조작 키를 안내합니다.

1. 권장 시스템 사양

항목권장 사양비고
운영체제 (OS)Ubuntu 22.04 LTS (64-bit Linux)제공된 설치 패키지 또는 실행 전용 런처 환경
그래픽카드 (GPU)단일 NVIDIA GPU (VRAM 12 GB 이상, 권장 16 GB+) / 듀얼 GPU 지원RTX 3080 12GB · 4070 Ti · 4080 · 4090 급 이상 권장 (단일/듀얼 GPU 자동 감지)
CPU / RAM16코어 이상 CPU · 시스템 메모리 64 GB 이상대규모 정밀도로지도 및 다중 배경 교통류 구동 기준
디스플레이1920×1080 이상 (듀얼 모니터 사용 시 편리)메인 4-Tab 창과 별도 3D 뷰어 창 동시 표시 가능

ℹ️ 실행 패키지 안내

프로그램은 배포 형태(설치형 패키지 또는 라이선스 보호 실행 파일)에 관계없이 제공된 실행 런처를 통해 동일하게 구동됩니다. 별도의 환경 설정 없이 메인 화면이 열리면 아래 5단계 순서로 시뮬레이션과 검증을 진행할 수 있습니다.

2. 기본 실행 5단계 절차

  1. 프로그램 실행 및 탭 이동: 런처를 기동한 뒤 상단 탭에서 [가상 주행 시뮬레이션](Tab 2)을 선택합니다(실차 로그 검증 시에는 Tab 1 또는 Tab 3 바로 사용).
  2. 권역 선택 및 주행 경로(S→G) 지정: 상단 구역 메뉴에서 시험할 지역(예: SEC02_테크노폴리스, KIAPI 등)을 선택하고, 좌측 2D 지도 위에서 출발 차선과 목적지 차선을 차례로 좌클릭합니다.
  3. 3D 월드 변환 및 로드: 상단 1열의 [① XODR 변환] 버튼을 누른 뒤 완료되면 [② CARLA 빌드] 버튼을 클릭하여 3D 시뮬레이션 월드를 구동합니다.
  4. 주행 조건·시나리오 설정 및 주행 시작: 상단 2열에서 차량 모델, 제어 모드, 목표 속도, 날씨, 주변 교통류를 설정하고(필요 시 우측 패널에서 위험 시나리오·고장 추가), [▶ 주행 시작]을 클릭합니다. [Pygame 창] 버튼으로 3D 화면과 실시간 파형을 확인합니다.
  5. 정량 검증 및 보고서 생성: 주행이 끝나면 [정량 검증 →] 버튼을 클릭하여 Tab 3에서 20개 안전 평가지표 결과를 확인하고, [검증 보고서 생성 →]을 눌러 Tab 4에서 PDF 성적서를 출력합니다.
